# Item Previews

[简体中文](README.zh.md)

A data-only package (`kind = "assets"`) that holds pre-generated item preview pictures. Other packages declare
`requires = ["bubblefighter.fantasy.item-previews"]` and read the files through the overlay package host:

```js
overlayBus.packageUrl('bubblefighter.fantasy.item-previews', 'pack.json')
```

The package changes nothing in the game by itself. See
[shared data packages](../../../docs/plugin-management.md#shared-data-packages-and-requirements) and
[package files](../../../docs/hook/overlay.md#package-files).

## The data folder is not in the repository

The pictures are game art. They are generated by the server repository's item viewer tool and must never be
committed (`store-plugins/**/data/` is ignored). The generated pack has this layout, which becomes the package's
`data/` folder:

```text
pack.json                    index of the pack
atlas/<hash>.webp            picture sheets, named by lower-case hexadecimal content hash
builds/<build id>.json       per-build item tables
```

## Filling it at packaging time

```sh
python tools/publish-store/stage_assets_package.py \
  --package store-plugins/BubbleFighter/bubblefighter.fantasy.item-previews \
  --pack <generated pack directory> \
  --output <new staging folder>
python tools/publish-store/publish_plugins.py --package <staging folder> ...
```

The script copies the manifest into the staging folder, copies the pack into `data/`, refuses links and unexpected
entries, and checks that every file named inside `pack.json` and `builds/*.json` exists. Unreferenced sheets are
reported as warnings. The publisher refuses to publish this package with an empty or missing `data/` folder.
