# 韩服认证组件

[English](README.md)

仅支持韩服 2026（`kr-1256`）的必装原生插件，要求使用最新版本。新增客户端时
在推荐列表固定勾选；未安装或未启用时不能启动该版本。其他版本不受影响。

组件通过 `native-login.toml` 校验程序时间戳、映像大小与原生函数特征，包括
加壳程序在运行中解包后的代码。必须有启动器创建的会话及完整服务器票据。
运行库就绪、原生连接和 GamePatch 完成后，在游戏 UI 线程完成启动状态交接，
并在登录界面创建前，用客户端自身的字符串分配方法将完整票据写入连接对象的
passport。随后由游戏原有登录流程发送，不再调用登录界面回调来提交票据。
不模拟键盘输入，不需要另起程序。

补丁交换后，先在 UI 线程完成启动状态交接，再等待登录界面创建；冷启动最多
等待 120 秒。仅替换已校验的登录目标构造函数，使其使用所选服务器地址；
relay 连接仍走原有路径。

不会修改 `login.ini`、主程序选择顺序、原有 messenger 转发、服务器校验或
其他玩法功能。游戏安全初始化与队列轮询入口经校验后适配到不运行独立游戏安全服务的托管启动环境。
原生受保护数值与设备信息处理保持原样。不匹配的程序或缺失
特征会拒绝加载；超时及提交阶段会写入日志，不记录票据内容。写入票据不等于
服务端已经接受登录。

0.1.2 版在插件入口执行期间，通过运行时 3.4.0 的认证授权接口获取票据和服务器
地址，不再独立解析 `session.toml`，避免会话新增字段导致插件内嵌的旧解析器
拒绝初始化。缺少授权、票据无效及地址解析失败都会记录具体阶段，不记录凭据。
已经发布的旧版本内容保持不变。
