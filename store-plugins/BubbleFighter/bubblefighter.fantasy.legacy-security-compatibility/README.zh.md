# 旧版安全模块兼容

这个可选补丁插件跳过旧版原生安全 SDK 的操作 19 身份上报。部分旧客户端切服后会在模块入口不可用时调用该函数，造成空地址崩溃。插件不恢复外部安全服务，也不修改游戏、中继、Center 或认证协议。

在 Launcher 的「插件」页导入此文件夹或 ZIP，再为待测试的客户端实例启用「旧版安全模块兼容」。修改选择后重新启动游戏即可，不需要更新 Launcher 应用或安装额外 DLL。关闭插件并重新启动即可恢复原有内存行为，磁盘中的游戏可执行文件不会被修改。

每个构建都使用各自完整的函数签名。定位签名仅将调用位置设为通配，以便识别原始状态和已经安装的补丁；独立的预期字节仍要求写入前该处是准确的原始调用。签名不存在或不唯一时不会写入。

## 调用约定

原包装函数将错误输出初始化为零，压入三个参数，以 stdcall 约定调用操作 19，随后把 EAX 截为低字节并与 1 比较。补丁清理相同的十二字节参数并将 AL 设为 1，保留原有的掩码、成功分支、异常栈清理及返回路径。插件不会伪造校验数据或种子表。

## 验证及范围

可对每个构建执行 `python tools/verify-plugin/verify_plugin.py <插件目录> --image <构建>=<解包后的可执行文件>`。签名和调用约定检查证明补丁与该映像匹配，不能代替游戏内切服及开局实测，也不代表旧版安全 SDK 的所有入口均已修复。本插件明确只处理身份上报入口，并不宣称完整移除原生安全模块。
