# 一键跑步

[English](README.md)

一个插件支持 KR2015（`kr-812`）、国服 2011-2016、印尼 2014、印尼 2015 和台服 TW454。
按一次设置中的前进键即可触发游戏原有的跑步流程，保留改键支持和原有移动限制。
KR1256 本身已内置此功能，因此不提供安装；其余现代版本仍待单独验证。

TW454 使用独立验证的输入分支，仅跳过首次按键或计时过期时的双击前进计时判断，
保留客户端原有跑步资格检查和松开按键后的处理。插件清单已声明台服兼容，
原生配置选择既有的声明式补丁实现。

国服 2011（`cn-279`）使用已通过客户端测试的原生前进计时器实现，已由原预览版
合并进本插件，不改写游戏指令。组件校验客户端时间戳、计时器函数和角色对象后，
在游戏窗口线程调用原有计时器。其他已支持版本继续使用各自校验过的分支补丁，
不会启动国服 2011 的计时器逻辑。不模拟键盘输入，不替换资源，不修改服务端。

启动游戏前启用插件即可。「单次按键跑步」默认开启。关闭选项或禁用插件后，
重新启动游戏恢复原有双击前进键行为，不会修改磁盘上的游戏主程序。
各版本通过同一个插件内的数据选择实现，无需另装 CN2011 Preview。
本插件不包含「前进起跳」功能。

分支补丁使用唯一特征定位并校验原始字节；加壳客户端通过运行时等待解包。
程序不匹配时拒绝修改。CN2011 已通过测试，不代表其他所有支持版本都已完成实机验收。
