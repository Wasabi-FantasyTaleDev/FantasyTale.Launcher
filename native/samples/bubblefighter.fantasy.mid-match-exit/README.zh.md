# ESC 提前离场（实验性）

[English](README.md)

所有支持版本共用一个可选插件 ID。目前只有 kr-812 的实现通过了离线验证；
其他版本需确认自身调用路径和原始字节后，在同一个插件内添加版本差异。

允许实机测试时，可通过启动器的插件导入功能导入此目录。它暂未作为内置默认
插件发布。“允许所有模式”默认关闭，保持原版规则；开启后放开已定位的模式和
Boss 存在限制，确认仍保留原有 Relay 路径；普通模式需要可用的 Relay 连接。初始化、上下文、连接
和防重复弹窗检查保留，特殊模式与会话退出仍走原有分支。

五个补丁位置已对韩服 2015 解包程序通过离线原始字节核验，启动器也能解析插件
及默认选项。这不证明所有模式已能正常退出：实际按键、取消、确认、服务端接受
退出请求、房间成员清理和退出后的继续游玩，仍需实机验证。此包目前不能宣称
已完成所有版本或所有模式兼容。

0.1.0 已实测能显示确认框，但未建立 Relay 连接时，确认没有效果。0.1.1 在普通
模式确认时实验性地改用原生主连接离场路径，服务端收到 506 并响应，但客户端
随后在对局渲染函数中崩溃。0.1.2 已撤回这一替代路径，缺少 Relay 时的普通离场
仍未完成。

关闭“允许所有模式”时不应用补丁。补丁加载后关闭插件，需要重新启动客户端
才能恢复原行为，不会即时撤销内存修改。本插件仅修改进程内存，不替换客户端
资源包。
