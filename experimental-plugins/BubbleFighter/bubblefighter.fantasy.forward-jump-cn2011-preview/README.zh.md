# 前进起跳 CN2011 测试版

仅用于 cn-279。普通移动路径开启旧客户端原生的前进起跳能力字段；跑步状态 301 另外绕过 `sub_7D6980` 中因缺少 `bubbleJumpEnable` 配置而拒绝请求的两字节门槛（RVA `0x7D69E4`），只在按住 W+空格期间临时修改，并在请求或跑步状态结束时恢复。函数其余状态、效果、资源和冷却检查继续由游戏执行。不模拟按键、不伪造装备或网络动作，修改仅存在于本次游戏内存。

先关闭旧版声明式“前进起跳”，仅启用本测试包；已验证的一键跑步可继续开启。测试 W+空格、跑步中 W+空格，并确认 A/D+空格、S+空格、原地跳及受限制时的动作保持原有行为。实际动作效果待实机验证。

本地研究版只在普通状态 101/102/103 临时开启能力，在跑步状态 301 使用受保护的跑步门槛，并在进入 104（翻滚）时恢复本插件自己的修改，避免把翻滚也变成可起跳。它仍未通过实机验收，不会默认启用或发布。CN2012 使用对应能力字段，另有特殊状态分支；本插件不授予那些状态。新版默认开启的初始化来源仍在研究。

此诊断版还会在 `fthook.log` 中记录发生变化的动作状态值，以及 W/空格输入标记。只在状态或输入变化时记录，用来确认是否存在尚未覆盖的状态，不会修改这些状态。
