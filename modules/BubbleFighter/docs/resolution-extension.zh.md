# 分辨率扩展

[English](resolution-extension.md)

可选插件 **分辨率扩展** 为游戏原生菜单补充显示模式。0.2.6 包含 **kr-812、
cn-404、cn-406、cn-706、cn-717、cn-735、id-400、id-1809** 的适配配置。
最初的 kr-812 扩展已由维护者实测成功；本次自定义设置和另外七个适配已通过
静态、合成验证，仍需逐版进行游戏内的实际显示验收。

CN2011（cn-279）、CN2012（cn-324）没有原生分辨率切换，因此不在适配范围。
kr-1256 已使用动态列表。后续代际的 cn-774、tw-454 不声明兼容此固定列表方案。
插件提供适配配置，不会开放启动器原本已禁用的客户端版本。

## 安装与设置

从商店安装此可选插件，然后为兼容客户端启用。插件声明的设置页面需要
启动器 0.1.33 或更新版本。也可以通过 **插件 > 导入插件** 导入本地包。
插件使用现有的公开原生 ABI，并已使用启动器运行时 3.7.0 验证。

打开插件的 **设置**，维护额外分辨率：

1. 输入宽度和高度，单位为像素，点击 **添加** 或按 Enter。
2. 点击对应的删除按钮移除自定义项；清单较长时在设置对话框内滚动。
3. 点击启动器的 **保存** 保留修改，或点击 **取消** 放弃修改。
4. 下次启动游戏后，在游戏原有的显示设置中选择分辨率。

这里只编辑额外清单，原有分辨率和自动发现的显示模式始终保留，相同尺寸会
自动去重。可以手动添加显卡没有枚举的超宽屏或中间尺寸。仅作用于菜单的适配允许
明确配置、非原生、未超过当前显示器且至少达到一档原始尺寸的选项出现。
其他候选仍沿用游戏对所选显卡的原生检查。添加尺寸不会创建驱动显示模式，也不绕过
设备初始化检查。

清单最多 256 项，内容不超过 4096 个 UTF-8 字节。保存的选项也支持输入
`1920x1080;2560x1440` 这类正整数尺寸，使用分号、逗号或换行分隔。
自定义设置页直接提供宽度、高度输入框。

## 生效方式

自定义清单和硬件显示模式在游戏启动时读取，修改清单或连接的显示设备后需
重启游戏。自动发现的列表沿用新版客户端的尺寸和宽高比策略，自定义项可以
额外补充。除上述明确配置的菜单候选外，实际选项仍取决于显卡驱动和游戏自身的硬件检查。

游戏原有的设置和保存流程保持不变。kr-812 会显示原有的重启提示，并在重启
后应用所选分辨率。此插件不为原本要求重启的客户端增加实时切换功能。

CN2013（cn-406）在扩展分辨率需要超出原有 1600×900 大厅范围时，会额外扩展
大厅画布，沿用游戏自身的控件居中、相机和界面缩放坐标。原生菜单中的
800×600、1024×768、1366×768、1600×900 继续使用原有布局，包括开启界面缩放
的情况；内部候选表中的其他原有尺寸也予以保留。此画布修复仅为 cn-406 开启，其他
版本继续使用各自的场景行为。维护者已在游戏内确认此画布修复正常。

本次自定义菜单修复通过全部八个已解包客户端的静态检查，以及 1,830 项原生合成检查，
包括 thiscall 栈平衡与当前显示器路径。该修订仍需游戏内菜单验收。
另行反馈的重启后全屏变窗口问题仍在调查，本次菜单修改不宣称已修复该问题。

关闭插件并重启即可恢复原有行为。已保存尺寸若不在原始列表中，游戏会按原有
逻辑回退到 1024×768。重启以使用扩展尺寸时，请保持插件开启。插件不替换游戏
文件，也不自行改写 `Option.ini`。

编译命令、各版本 TOML 的配置方式和验收清单见
[技术说明](hook/resolution-extension.md)。
