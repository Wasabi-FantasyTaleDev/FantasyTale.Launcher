# 泡泡战士集成源码

[English](README.md)

本目录是泡泡战士模块的源码快照，包括客户端定义、原生插件实现、资源组合工具及模块文档。它以普通文件纳入启动器源码仓库，不包含嵌套仓库或以前的 Git 历史。

共享启动器解决方案和 SDK 位于仓库根目录。托管、原生及前端构建命令请从根目录[贡献指南](../../CONTRIBUTING.zh.md)开始。部分独立集成工程仍要求共享源码布局；存在工程文件不代表每个工程均可在本目录独立构建。独立原生 SDK 及其校验工具保留固定版本。

插件定义声明兼容版本、保存选项、资源编辑和已验证的原生补丁。最终用户安装包通过配置的插件商店分发。本源码快照不包含已编译游戏插件、客户端归档、原始或生成的游戏字体、角色模型素材及专有媒体。字体与资源打包工具需要使用者自行提供原始文件，请遵循对应工具的输入说明。

参见 [LICENSE](LICENSE)、根目录[第三方声明](../../NOTICE.md)和本模块 `docs/` 目录。游戏名称与商标属于各自权利人；源码开放不授予游戏素材的再分发许可。
