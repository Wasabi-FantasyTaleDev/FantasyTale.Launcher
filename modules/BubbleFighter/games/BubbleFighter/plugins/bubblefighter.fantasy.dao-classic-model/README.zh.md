# 旧版皮蛋模型

使用皮蛋重做前的默认角色模型。启用后在启动游戏时应用，游戏退出后自动还原。
关闭插件后，下次启动使用原始资源。仅替换已有默认模型成员，保留时装和其他资源。

支持构建：cn-0-92-1, cn-774, kr-1256。国服2018对应 cn-0-92-1，需启动器具有匹配的客户端配置；
国服2019为 cn-774，台服2019为 tw-454，韩服为 kr-1256。
台服2019原本就是旧版皮蛋，因此不提供该构建的皮蛋替换。

台服角色名称“藍寶／痞子妹”和韩服名称“다오／디지니”取自客户端数据。
插件由用户从商店自行安装，不改变客户端策略。归档、安装与还原检查已自动执行；
各版本的角色显示、时装和表情仍需实机验收。
