# 场景样式选择

调整大厅和广场的样式和糯米/贝尼的服装。

分别为「大厅」和「广场」选择「原版」或「下雪」。场景原版使用当前客户端自身的场景文件；下雪使用韩服 2011 冬季场景和配套贴图。1.0.2 支持 cn-279、cn-324、cn-406，需要 Launcher 0.1.66。

「下雪时使用圣诞BGM」和「为糯米和贝尼穿上圣诞服装」默认开启。圣诞 BGM 使用客户端内置的对应音乐事件，只应用于选择下雪的场景。关闭后保留客户端原始音效表；部分客户端的原版广场本来就使用圣诞音乐。

糯米的服装可选「默认／原版／圣诞」，贝尼的服装可选「默认／原版／圣诞／小僵尸」，初始都选默认，保留当前客户端自带的 NPC 资源。CN2011 的贝尼原本就是正常模型，因此原版也保留它现有的资源；CN2012／CN2013 的贝尼原版采用韩服 2015 模型，小僵尸采用国服 2012 模型。糯米原版保留普通服装。服装可独立于场景选择。自动换装开启时，大厅或广场切到下雪都会为两位 NPC 选择圣诞服装；任意场景已经下雪时打开自动换装也会选择圣诞。之后仍可手动修改，保存和重新加载不会覆盖手动选择。

设置在下次启动游戏时生效。通用资源合成器合并成员修改，通过现有冲突对话框报告插件冲突，并在游戏退出后还原原文件。本插件不替换功能界面、认证、可执行指令、相机代码或分辨率扩展 Hook。原生分辨率布局和 CN2013 扩展画布修复继续由客户端及分辨率扩展插件负责。

后续可增加枚举值与资源计划，保留现有设置键。游戏资源只生成到忽略的打包目录，不进入代码仓库。
