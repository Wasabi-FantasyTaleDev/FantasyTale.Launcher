# 新旧角色模型切换

这个资源插件可以为客户端实际提供的每个角色单独选择原版、新版或旧版。
首次安装时选项为空，客户端归档不会被修改；选择客户端本来就提供的模型代际
同样不会产生修改。

启动器从当前客户端读取 BFZ 或 PKN，合并所有已启用的成员修改，校验未修改的
归档记录，再通过可恢复的运行时事务应用。游戏退出后会恢复原文件。准备过程
中断或文件损坏时会在下一次启动前恢复；输入归档和选择未变化时复用已校验缓存。
启动时显示实际的归档准备进度，也可以在替换前取消。

插件定义只包含计划和内容寻址载荷名称，游戏资源载荷由商店分发，不进入源代码
仓库。后续资源插件可以使用同一归档合成器和角色模型能力，安全地共同修改一个
物理归档。

资源范围依据 cn-717、cn-735、cn-738、cn-742、cn-774 的同地区代际对比，并与
kr-812、kr-1256、tw-454 交叉检查。目标版本独有的后续时装会保留；无关
的地区更新以及宝宝的两项仅特效事件修改会排除。

旧版黑妞包含已审阅的装备头部及其配套贴图。对于会通过深度写入挡住独立脸部的
透明像素，制作工具会按贴图范围移除对应头部三角形区域，脸部仍保留原来的位置。
不透明的帽子、材质分组和骨骼权重均会保留；没有相交透明区域的头部不作修改。
默认头部与用户已验证通过的 1.0.4 修复逐字节一致。装备部分已有 Item Viewer
三视角对比，但这不代表每款装备和每个地区客户端都已完成游戏内验收。

制作插件需要装有 NumPy、Pillow 的 Python、源成员清单、变化边界证据、已审阅的
透明区域证据及配套 .NET 资源提取工具。转换前会校验源模型和引用贴图的记录哈希，
转换后也必须符合已审阅输出的哈希。每款装备的贴图会放在对应模型旁，避免地区
共享贴图库的差异；各目标版本仅生成实际需要的修改。
