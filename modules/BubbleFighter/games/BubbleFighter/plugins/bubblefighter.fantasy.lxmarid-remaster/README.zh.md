# 蓝妹妹新版模型

此商店可选插件为蓝妹妹（LXMarid，角色编号 300010）替换重做后的基础模型、
脸部和默认纹理，不修改其他角色、时装、角色拥有状态或服务端行为。

在对应客户端中启用插件后启动游戏即可。启动器会校验补丁、备份原文件，
并在游戏退出后自动还原。关闭插件后，下次启动使用原始资源。

支持 cn-324、cn-404、cn-406、cn-706、cn-717、cn-735、kr-812、id-400、id-1809。
其中 cn-735 是国服 2016 年 0.2.70.4，使用单独制作的 PKN；其余使用 BFZ。
不改变 cn-717、cn-735 现有的 modern 家族分类。
国服 2011 没有该角色，不适用；cn-774、tw-454、kr-1256 已自带新版模型，无需安装。

资源来自 cn-774，并与 kr-1256 的 46 个共同文件逐一核对哈希。
cn-735 的补丁保留原包中其余 985 个文件，只替换 Default 目录。
繁体中文名称「優雅小蜜桃」和韩文名称「럭셔리 마리드」均取自客户端角色数据。
CN2012 手动替换已通过用户实机验证，其余版本仍需逐一确认游戏内显示效果。

打包命令与资源证据见同目录 README.md。游戏资源不提交至代码仓库，也不适用
仓库的软件许可证。此插件由用户自行在商店安装，不加入 client policy。
