# 海盗表情差分修复

此可选资源插件修复国服2011—2015及2019客户端中，以皮蛋骨架制作的狸猫海盗
缺失表情时间表的问题。启动游戏前启用插件即可。需要包含缺失资源档案
创建支持的启动器0.1.62或更高版本。

支持的客户端标识为 `cn-279`、`cn-324`、`cn-406`、`cn-404`、`cn-408`、
`cn-705`、`cn-706`、`cn-717` 和 `cn-774`。其中 `cn-705` 已有本地可执行文件识别
证据，但目前没有内置版本定义。未列出的国服客户端、韩服及其他地区版本
不在本插件的适配范围内。

受影响的海盗使用角色类型 `1` 和头部装备 `100184`；通用海盗头部装备
`100218` 在角色类型为 `1` 时也使用同一套表情。客户端现有的脸部网格
和表情纹理已经完整。插件仅补入来自 kr-812 的193个
`Models/Characters/Dao/raccoon2/*.face` 表情时间表，并已逐一验证其引用
的全部纹理与所有目标客户端一致。插件不替换角色网格、纹理或玩法配置。

国服2011和2019将这些成员合并到各自现有的模型资源包，并保留原有PKN
格式和所有原有成员；使用BFZ的客户端则临时
创建缺失的独立表情档案。启动前由已有资源准备流程合并插件内容、检查冲突
并验证数据。游戏退出或中断启动恢复时，还原原资源包或删除新建的表情档案。
若目标表情档案已经存在，启动器会拒绝覆盖。

源码仓库仅保存插件定义、打包规则和打包工具。解包后的客户端资源应保存在
被Git忽略的输出目录。使用 `tools/package-pirate-expression-fix.py`、
已审查的资源清单和现有 `CharacterResourceMaterializer` 工具生成安装包。
打包过程重新检查客户端时间戳、完整成员集合摘要和档案读取结果，随后生成
插件目录及ZIP。

离线资源与恢复验证用于确认候选包的文件行为，仍需要在实际海盗对战中进行
表情显示验收。

角色与装备的对应关系及客户端读取函数地址见
[客户端证据](../../../../docs/hook/pirate-expression-fix.md)。
