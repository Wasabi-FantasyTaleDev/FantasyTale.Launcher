# 在另一台电脑测试数字血量候选版

[English](x64-plugin-testing.md)

使用官方 Windows x64 便携启动器包。更新后在关于页核对正在运行的版本；
检测到新版不代表已经安装。
将 ZIP 完整解压到可写目录，例如 `D:\FantasyTaleLauncher`，然后运行目录中的
`FantasyTale.Launcher.exe`。不要在压缩包内直接运行，也不要只复制 exe。
包内包含 .NET 运行库，无需安装 .NET SDK。如果启动提示缺少 WebView2，
安装微软的 x64 Microsoft Edge WebView2 Evergreen Runtime 后再次打开。

启动器、Photino、WebView2Loader、运行库和独立更新程序都是 x64。
注入游戏的 Hook 和数字血量 DLL 为 x86，因为支持的游戏客户端是 32 位。
包内不含游戏客户端、保存的账号凭据或已登录会话。

## 配置客户端

1. 从原电脑复制整个韩服 2015 客户端目录。当前数字血量候选版支持
   `kr-812`；其他版本不能作为同一条件下的对照。仅复制 exe 不够。
2. 启动器选择泡泡战士，进入客户端页，将复制目录作为安装路径添加，
   让启动器识别版本。
3. 服务器选择 Bubble Fighter Fantasy，使用该服务器上的账号登录。
   账号属于所选服务器。
4. 商店使用内置 Fantasy Tale 来源，为所添加的客户端选择数字血量
   `0.2.9`。版本按新到旧排列，核对实际选中的版本，不要认为已经安装的旧版
   `0.2.7` 会自动变成新版。
5. 在插件页为该客户端显式启用数字血量。字体颜色选黄色，位置选原生，
   开启百分号，关闭实际血量。同一客户端只能选择该插件的一个版本，切换版本会
   转移启用状态和兼容的设置。
6. 启动游戏并进入对局，观察 HP 圆环上方的血量数字，再减少血量，检查
   百分号是否跟随数字位数变化。修改设置后需要重新启动游戏进程。

## 反馈结果

记录血量数字及百分号是否出现、位置、是否延迟，以及调整窗口后是否变化。
对局截图和本次数字血量插件日志比仅有启动截图更有用。可选的时间诊断
记录有次数上限的绘制提交快照，但它不能证明像素实际可见。

维护者已经确认切换新版插件后，百分号图片和原生位置正常。早期对照用的是
`0.2.7`，不能仅归因于 ARM64。新的对照应保持两台电脑的插件版本、设置和客户端
文件一致。目前只公开支持 `kr-812`；其他 legacy 构建仍处于研究状态。启动器正式
及原始预览更新入口均保留，并提供内容相同的 schema 1 索引。
