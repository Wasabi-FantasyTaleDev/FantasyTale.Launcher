# 连接设置

首次读取服务器信息时，遵循单个服务器的显式地址偏好或全局“所有地区优先 IP”设置。
默认“仅中国大陆”不会预先假定未知服务器位于中国。普通 HTTP 可将保存的域名解析成 IP 访问，
HTTPS 仍保留证书主机名；公开目录读取失败时，在支持的情况下尝试另一种地址方式。
服务端声明访问要求后，认证请求遵循该要求。安全的 API 读取遇到暂时性传输错误或 502／503／504 时，
会在原有调用截止时间内重试一次。认证、签发启动票据和申请选服授权的 POST 不会重放。
目录自身超时会显示为网络超时，用户主动取消启动则单独处理。

[English](network-settings.md)

连接设置包含 IP 访问策略和 GitHub 镜像加速。设置里的安装目录入口暂时隐藏，
客户端文件夹仍可从“客户端”页面打开。更新偏好继续保留在“更新”选项卡。
商店来源可单独覆盖全局 IP 访问策略；新增和编辑来源时也可以设置此选项。

## 服务器 API 连接方式

服务器编辑窗口另有“使用 HTTPS”开关，默认关闭。关闭时 API 请求保留配置的
地址，即使服务端公布了 HTTPS 地址也不自动切换。开启时优先使用服务端公布的
HTTPS 地址，否则将配置的 HTTP 地址切换为 HTTPS，并保留路径和非默认端口。
直接配置的 HTTPS 地址仍使用 HTTPS。群服认证支持配置选择的两种连接方式，
“优先 IP 访问”与此开关独立。

## 服务器 API 连接方式

服务器编辑窗口保留“使用 HTTPS”开关，默认关闭。关闭时继续使用配置的 API
地址，服务端公布的 HTTPS 地址不会自行替换 HTTP 地址。开启时优先使用服务端
公布的 HTTPS 地址，否则将配置的 HTTP 地址切换为 HTTPS，并保留路径与非默认
端口。直接配置的 HTTPS 地址仍使用 HTTPS。认证与群服目录请求均支持配置选择的
HTTP 或 HTTPS。“优先 IP 访问”与此开关独立。

## GitHub 镜像源

展开“GitHub 镜像加速”可以选择“自动”或指定镜像源。标题右侧的开关独立控制
是否启用，不受展开状态影响。“测速”打开可滚动的独立结果对话框；“使用”会
选择对应节点并启用镜像加速。测速失败的节点仍可选择，因为不同网络的连通性不同，
而且可能随时发生变化。

没有独立的检测记录时，启动器在后台检测一次 IP 所属国家或地区。
之前安装过、尚无此检测记录的用户也会执行，与登录和安装次数无关。
中国大陆（`CN`）在主界面显示后弹出建议对话框，卡片里的开关默认开启；
仅保留“确定”按钮，用来保存当前开关选择，包括关闭。仅检测到地区不会自行启用。
其他国家和地区默认关闭，不弹出此对话框。用户手动选择优先于尚未完成的检测，
并在重启后保留。无论检测完成还是失败，都会保存检测标记，之后不重复检测；
失败时保留原来的开关设置。尚未显示的建议在重启后保留；对话框实际出现时另存
展示标记，即使确认前关闭程序，下次也不会重复弹出。
这些标记不包含 IP 地址或国家地区字符串。

随程序提供的 `github-mirrors.toml` 包含独立镜像源和目录节点快照。每次测速会从
公开目录当前的同源脚本中读取节点，不执行远程脚本。单个脚本读取失败不会丢弃
其他脚本中找到的节点；目录无法访问时继续使用随程序提供的快照。
已保存选择的节点即使在之后的目录更新中消失，也会保留。测速失败不会删除节点。
标记为 `directory_snapshot = true` 的行在成功获取目录后由最新目录替换，
其他配置源保持独立。

测速通过并发、有字节范围限制的请求读取配置中的公开压缩包，耗时包含连接建立。
显示的是小样本速度，不代表完整下载过程中保证达到的速度。并发量、采样大小、
超时和文件头特征由随程序提供的 TOML 配置。

自动模式在下载 release 或 archive 文件前测速，按结果顺序尝试可用节点。
手动模式先尝试指定源，再尝试其他源，最后回退到 GitHub 直连。一次下载中每条
路由最多尝试一次；响应正文传输中断时，在下一个源继续下载对应哈希的临时文件。
长度、范围或哈希不正确时丢弃临时内容再尝试下一个源。完整文件只有通过原始大小
和 SHA-256 校验后，才能替换目标文件。用户取消后不再尝试其他源。
测速使用自己的节点超时，不占用实际下载请求的响应头等待时间。
普通元数据请求使用当前节点顺序，不等待 release 测速。

仅对已识别 GitHub 站点的公开 HTTPS GET 请求使用镜像。写请求、携带认证或
Cookie 的请求和其他网站继续使用原连接。镜像设置不会改变更新清单、签名、
完整性校验、安装策略、外部替换、健康确认或回滚流程。

## Overlay 开发者设置

“开发者选项”中的 UI Overlay 测试采用可展开的设置卡片。标题开关决定下次启动
游戏时是否显示测试消息。“框外点击穿透”保留在展开区域内，测试关闭时也能配置。
两项设置都在下次启动游戏时生效。
