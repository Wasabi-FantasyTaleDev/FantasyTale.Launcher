## 压缩依赖审查

应用运行时解压现已统一使用随附的原生 7-Zip。客户端安装、启动器整包更新回退及插件 ZIP 导入共用 `NativeArchiveDecoder`，已移除 SharpCompress 和原来只处理 RAR 的适配器。发行工具及合成测试仍可使用标准库创建 ZIP，这些不是随应用部署的解压引擎。

共享适配器先读取并校验目录，再写入文件，拒绝不安全路径、别名冲突、链接及特殊条目，保留各入口的文件数和字节上限。写入时同时计算哈希，并验证原生校验和；发行清单中的文件哈希在事务安装前核对。密码及清单限定的 RAR 分卷通过原生回调读取，按字节拆分的 ZIP 和 7z 通过可定位的跨卷视图读取，无需复制合并压缩包。

目前要求 Windows，支持随附的 x64 和 ARM64 二进制；其他平台明确报不支持。此次改动不代表冻结发行包已经携带新收集的源码和许可文件。回归范围包括 ZIP、7z、RAR4/RAR5、加密、固实包、分卷、错误密码、缺卷、非法路径、损坏、清单哈希不符、取消及事务恢复。
