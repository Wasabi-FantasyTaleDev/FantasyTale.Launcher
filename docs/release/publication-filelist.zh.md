# 发布文件清单

Launcher 的 `current.toml` 已经包含本地生成的文件列表，每行记录安装路径、
内容寻址的下载路径、字节数和 SHA-256。发布工具读取上一份公开清单，并核对
其内容与发布开始时取得的清单哈希一致。下载路径、哈希、大小均相同的对象
直接复用，不再下载或上传。只有 `objects` 目录下以完整 SHA-256 命名的对象
才可复用。新增或清单未记录的对象仍校验公开下载内容。所有内容准备好以后
才更新清单，并保留并发发布冲突检查。

这项优化不会逐次审计已发布对象被其他工具修改的情况；客户端下载后仍按
清单校验实际内容。商店和插件的发布路径、完整压缩包校验尚未采用这项优化。
Launcher 的版本检查只读取更新清单并比较版本，不下载所有内容。本地暂存
和下载完整性校验与版本检查是不同阶段。
