# 系统字体与私有构建

[English](system-fonts.md)

公开源码不包含字体文件。正文使用 Windows 已安装的字体；图标依次使用
Segoe Fluent Icons、Segoe MDL2 Assets。只有未提供私有字体时，时钟和禁止图标
才使用内联 SVG；账号 SVG 不变。

本机构建可在 `web/private-assets/SEGOEICONS.TTF` 放置另行取得的字体。
整个目录均被 Git 忽略。Vite 启动时检测文件，将其作为带哈希的构建资源打包，
同时恢复时钟和禁止图标的原字形。构建不会下载字体。正常 Launcher 打包命令也
执行这套前端构建。设置 `FT_SYSTEM_FONTS_ONLY=1` 可显式禁用私有字体；
更改文件或选项后需重启开发服务器。

2026-10-21 本机 cmap 检查显示 Fluent Icons 覆盖全部 66 个映射字符，MDL2 覆盖
64 个，缺少时钟 U+E917 和禁止 U+E733。这只覆盖本机字体版本，不代表全部历史
Windows 10 版本，真实 Windows 10 界面验收仍需单独进行。公开源码构建的系统图标
形状可能不同；私有构建保留此前随包字体的行为。

类型检查及两种生产构建均通过。私有构建中的字体 SHA-256 与提供的文件完全一致，
系统字体构建没有字体文件。最终本机构建产物已恢复为私有字体模式，冻结发行包未改。
原字体保留在私有目录，也仍存在于 Git 历史；公开历史及发行权限审查仍需分别完成。
