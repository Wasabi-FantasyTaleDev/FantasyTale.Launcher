# Ban Pick（禁选）编辑器演示

[English](README.md)

这个 Vue 3 预览参考装备界面的背包部分，提供武器、角色、服装和饰品四个分类，
以及原版三列三行的背包网格、多语言搜索、原生子分类页签、分页和分类禁用数量。
主分类、原生 checkbox、最右侧搜索框保持同一行；checkbox 在搜索框左边，可筛选已禁用物品。
分类及按钮文字采用细描边，不叠加偏移阴影。底部按钮作为一组排列，v1 靠右、v2 居中。
点击物品会修改草稿；应用后保留在当前页面的内存中，取消或关闭会恢复上次应用的选择。
刷新页面会重置当前草稿。“预设方案”按钮打开独立的原生主题弹窗，支持保存、同名覆盖、载入和删除，通过浏览器
localStorage 跨刷新保留，包括全允许的空方案。存储失败会显示错误，并保留已有方案列表。
本演示尚未向服务端发送房间规则，也未在游戏会话中执行禁用。

共享游戏 UI 库导出了 `BfBanPick`。宿主提供翻译文案、物品数据、透明预览图地址
和由物品编号组成的 `modelValue` 数组、原始分类素材及已保存方案。组件发出
`update:modelValue`、`apply`、`cancel`、`save-preset`、`delete-preset` 和 `error` 事件；
存储和网络通信由宿主负责。

## 准备本地私有资源

请使用持续维护的 `tools/item-viewer` 源码和其中的 `kr-812` 配置。
已退役的独立目录使用旧的镜头、姿势和武器绘制规则，准备脚本会拒绝该目录。
Python 需要安装查看器使用的 numpy 和 Pillow，以及导出浏览器字体使用的 fontTools。
查看器显示的版本号仍为 `0.1.0`，因此 `preparation.json` 会记录 Python 源码和配置文件
的哈希，不能仅凭版本号判断源码是否最新。

从启动器仓库根目录运行，替换下面五个输入目录：

```powershell
$ViewerRoot = 'D:/path/to/maintained/tools/item-viewer'
$ClientRoot = 'D:/path/to/kr-812/client'
$TextClient = 'D:/path/to/Chinese/2015/client'
$V1Client = 'D:/path/to/Chinese/2011/client'
$FontData = 'D:/path/to/Chinese/client/Data'
python tools/game-ui/ban-pick-demo/prepare.py `
  --viewer-root $ViewerRoot --client $ClientRoot --text-client $TextClient `
  --v1-client $V1Client --font-data $FontData `
  --output artifacts/ban-pick-demo/resources
```

v1 的窗口、checkbox、卡片、页签、按钮和说明表单全部读取国服 2011 客户端；
v2 的对应资源全部读取国服 2015。每份清单分别记录自己的归档来源，主题不跨客户端混用。
添加 `--assets-only` 可以只刷新两套主题，保留已有道具表、字体和预览图；
缺少完整准备结果的目录会被拒绝。

国服字体目录须包含 `GB13000.ttf` 和 `DF_GB_Y9.TTF`，韩服客户端提供
`Data/NexonBTBold.otf`、模型及镜头规则。该 CFF 字体声明了 TrueType 的 maxp 格式，
旧 kerning 表也有不一致的长度；生成的 `NexonBTBold-web.otf` 规范化这些表，
保留全部字形、轮廓、提示和字宽，并保留原字体。`preparation.json` 记录两份字体的哈希。
国服客户端提供 `Config/ShopItem2.xml` 和
UTF-16、tab 分隔的 `StringTable/TranslatedXmlTable.csv`，正式中文翻译优先于 XML
中尚未翻译的字段。样例名称不进行手工翻译，缺少原生中文名称的样例会被拒绝。
繁体中文暂时共用原国服简体道具文案；没有官方英文名称的语言保留原韩文名称。
缺少描述时会在界面中注明。脚本只读取客户端归档，导出 `items.json` 声明的 47 个样例，
并刷新已有 PNG。输出、字体、客户端精灵图和截图均保存在忽略的 `artifacts/` 下，不可提交。

本次审查使用的 `tools/item-viewer` Git 树为
`b2cc8e9956d57a1c652588567def797deaee8ca6`，包含背包预览修复 `276b015c`
和来源证据修正 `6532d1b3`。描边由查看器原有的反向外壳绘制生成，演示没有添加
CSS 描边或修改模型几何。

样例包含两把大锤、两种手雷，以及原生头饰分类下的三种水晶：超级击爆加速水晶、
信天翁翻滚水晶、卓越加速水晶。水晶的 `standalone_slot` 声明只使用道具自己的模型与动作，
按声明的旋转方向及投影几何等比取景，并保留描边空间。适配器不修改持续维护的查看器。
导出清单将镜头标为 `demo-standalone-fit`，尚未确认官方独立道具镜头的调用路径。
准备记录同时保存适配器与样例定义的哈希。

## 运行和构建

```powershell
cd web
npm ci
npm run dev:ban-pick
npm run build:ban-pick
```

预览地址为 `http://127.0.0.1:4187/`。生产构建输出到
`artifacts/ban-pick-demo/dist/`，包含已准备的本地私有资源。
支持简体中文、繁体中文、韩文、英文、印尼文、越南文和泰文。
预览按可用宽度和高度适配 v1 的 584×949 或 v2 的 584×944 逻辑窗口，保留完整背包和说明布局。
1024×768 下将预览工具栏放到侧边，完整窗口无需滚动。标题、名称、状态及按钮使用
浏览器直接绘制的 SVG 文字，按最终显示尺寸取整数像素字号，不缩放文字位图。
移除了原版的左侧人物预览；原生说明面板占满背包下方的宽度，内部标签和分区同步拉宽。
预设操作位于独立的 320×205 弹窗。可以通过 `?theme=v1`、`?theme=v2` 或工具栏
切换主题，切换时保留当前选择草稿。

## 原版界面证据和验证

- `Ui/DlgInventory6.ui` 声明九个 172×172 标记，X 坐标为 449/629/809，
  Y 坐标为 140/318/496。背包图集提供 182×183 普通和选中卡片边框，居中裁成 172×172，
  去掉外侧发光留白，不缩放内部几何。水平和垂直间距保留 180 和 178 像素；
  透明预览区域为 164×120。每页显示九件道具，保留原版三列三行。
- `Ui/UiScheme.ini` 和 `Images/Ui/` 提供现有 `BfWindow`、checkbox、确认／取消按钮、
  面板皮肤和横向分页素材。主分类页签分别保留 v1 的 67×32 和 v2 的 67×27 尺寸，分类标识和顺序读取客户端表。
- 悬停更新说明，不显示黄色外框；`inventory_use.png` 原生内框表示禁用。私有导出仅去掉
  图片烘焙的状态文字，界面叠加对应语言的状态。卡片底部没有 checkbox。名称按可见字形边界在白色名称栏中居中；
  状态文字与图集里的灰色状态栏对齐。
  黄色“已禁用”位于模型区域左上角并向内留距，底部“允许使用”和“已禁用”使用相同灰色。
  两套主题采用完整原生子分类顺序：步枪、散弹枪、狙击枪、手枪、近距离武器、特殊武器；
  饰品依次为头饰、美容、配饰、背装，水晶归在头饰。
- `Ui/DlgItemInfo.ui` 分别提供两套说明布局：v1 保留蓝色宣传语栏和其下方的道具名，
  v2 保留绿色道具名称栏，`kr-812 sub_95BB60` 将选中
  道具的名称、宣传语、说明及额外描述填入标签。保留源表的文字对齐及纵向分区，横向坐标由原始的 420／417 像素扩展至 554 像素。
- `kr-812 sub_9B23D0` 为物品视图增加 `sin(time * 2*pi / 2000) * 2.5`。
  组件采用同一周期和振幅，页面隐藏时暂停，并遵循减少动态效果的系统偏好。
- 原始字体表将 Default／DefaultBold／NexonBTBold 映射到 `GB13000.ttf`（W7），
  将 Malgun 映射到 `DF_GB_Y9.TTF`（W9）。按用户要求，本演示将 700 字重映射到
  现成的较粗 W9 字形，不由浏览器合成加粗；这与原表的 400 字重是不同的设置。
  韩文标签保留 NexonBTBold。按钮按字形实际宽度收紧留白，切换指针状态时保留
  稳定节点，避免丢失点击。窗口和面板仍使用按整数边界合成的完整图像。
  标题、名称和状态的矩形读取各自图集色带，并按实际字形居中。
- Vite 更新或完整导出 `ui.json` 后会重载样式及资源清单。JSON 先写临时文件再替换；
  绘制错误会传给宿主，不再静默留下空白名称。字体加载错误注明字体及字重。
- 严格 Vue TypeScript 检查和 Vite 生产构建通过。浏览器检查覆盖搜索和禁用筛选组合、
  从筛选结果取消禁用、拖动／点击轨道／键盘分页、应用和取消后的恢复、预设持久化及删除、四个分类、
  中、韩、英文显示、图片加载及 400 像素窗口。共享绘制器回归测试验证原生控件挂入 Vue 宿主后
  仍能发出事件：事件从已挂载的控件发出，不再发给脱离页面的构建容器。
- 使用真实客户端导出皮蛋，开启描边与仅关闭描边的两张 328×240 图有 1,740 个像素不同。
  灰色背景对照确认黑色轮廓来自查看器绘制。

浏览器字体审计确认 18,280 个字形轮廓、17,258 个 Unicode 映射、字宽及 kerning 与原文件一致，
16 项 FreeType 文字栅格对照也完全一致。

ItemViewer 的部分配饰挂点仍处于推断阶段，导出清单保留了这些警告。
相关样例需要继续校准挂点，才能作为精确还原原版的预览图；这不影响演示的物品选择和分类操作。
